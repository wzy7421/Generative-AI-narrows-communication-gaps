# Analysis code

This directory supports the analyses reported in the manuscript and Supplementary Information.

## Analysis workflow

The reproducibility workflow covers:

1. Participant-flow validation and study-specific analysis samples.
2. Construction of baseline advocacy-capacity and quality variables.
3. Study 1 writer-level models and capacity-gap contrasts.
4. Study 2 fixed-content provenance contrasts for support and approval.
5. Study 3 marginal approval probabilities, net outcome equalization, gap-level conversion loss, and covariance / graph-sensitivity analyses.
6. Study 4 generic-referenced support contrasts and descriptive secondary outcomes.
7. Manuscript figures and supplementary-table outputs.

The Study 3 focal approval model does not condition on post-treatment claim quality, consistent with the manuscript specification.
